## 👨‍💻 About Me

I'm interested in **DevOps, Cloud Infrastructure, Automation, and Observability**.

My current focus is building and improving infrastructure using:

* ☁️ **AWS** for cloud infrastructure
* 🐳 **Docker & Kubernetes** for containerization and orchestration
* 🏗️ **Terraform** for Infrastructure as Code
* 🔄 **GitHub Actions, Jenkins & Argo CD** for CI/CD
